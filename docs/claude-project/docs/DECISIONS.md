# Architecture Decision Records

One entry per decision. Append new ADRs; never rewrite a past one in place.
If a decision is reversed, add a new ADR that supersedes it and says so
(name the superseded ADR explicitly).

Format:

```
## ADR-001: <short title>

**Date**: YYYY-MM-DD
**Status**: Accepted | Superseded by ADR-XXX

**Context**: what problem/question this decision addresses.

**Decision**: what was chosen.

**Rejected alternatives**: what else was considered and why it lost.

**Consequences**: what this makes easier/harder going forward.
```
